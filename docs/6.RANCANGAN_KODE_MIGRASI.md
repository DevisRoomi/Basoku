# RANCANGAN KODE MIGRASI DATABASE BASOKU

Dokumen ini berisi rancangan kode migrasi Laravel untuk enam tabel database **BASOKU**. Seluruh kode di bawah ini merupakan rancangan persiapan yang **belum diterapkan ke folder `database/migrations/` aktif**, guna memastikan skema dan relasi telah ditinjau dan disetujui terlebih dahulu.

---

## 1. Urutan Eksekusi Migrasi & Ketergantungan Foreign Key

Urutan migrasi disusun secara ketat agar tabel induk (*parent table*) selalu dibuat mendahului tabel anak (*child table*):

```
1. users (File bawaan 0001_01_01_000000_create_users_table.php + kolom role)
2. materials (Tabel independen katalog bahan)
3. recipe_configurations (Tabel independen konfigurasi preferensi resep)
4. saved_recipes (Tergantung pada users dan recipe_configurations)
5. orders (Tergantung pada users dan recipe_configurations)
6. order_items (Tergantung pada orders dan materials)
```

---

## 2. Rancangan Kode Setiap File Migrasi

### A. Penyesuaian Migrasi `users`
* **File Target Aktual**: `database/migrations/0001_01_01_000000_create_users_table.php`
* **Strategi**: Karena database `basoku` masih bersih (0 tabel) dan tabel `users` belum pernah dibuat di MySQL, cara paling aman dan efisien adalah menambahkan kolom `role` langsung pada deklarasi tabel `users` bawaan, sehingga tidak terjadi pembuatan tabel ganda (*duplicate table*).

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    /**
     * Run the migrations.
     */
    public function up(): void
    {
        Schema::create('users', function (Blueprint $table) {
            $table->id();
            $table->string('name', 100);
            $table->string('email', 150)->unique();
            $table->timestamp('email_verified_at')->nullable();
            $table->string('password', 255);
            $table->enum('role', ['customer', 'admin'])->default('customer');
            $table->rememberToken();
            $table->timestamps();
        });

        Schema::create('password_reset_tokens', function (Blueprint $table) {
            $table->string('email')->primary();
            $table->string('token');
            $table->timestamp('created_at')->nullable();
        });

        Schema::create('sessions', function (Blueprint $table) {
            $table->string('id')->primary();
            $table->foreignId('user_id')->nullable()->index();
            $table->string('ip_address', 45)->nullable();
            $table->text('user_agent')->nullable();
            $table->longText('payload');
            $table->integer('last_activity')->index();
        });
    }

    /**
     * Reverse the migrations.
     */
    public function down(): void
    {
        Schema::dropIfExists('users');
        Schema::dropIfExists('password_reset_tokens');
        Schema::dropIfExists('sessions');
    }
};
```

## 3. Daftar Keputusan yang Masih Perlu Dikonfirmasi

1. **Definisi Nilai Rasio di `recipe_configurations`**:
   * Kolom `meat_ratio`, `flour_ratio`, dan `seasoning_ratio` disiapkan bertipe `DECIMAL(8,4)` sesuai Dokumen 2.
   * *Status*: Dipertahankan sesuai dokumen, namun implementasi formula rasionya belum boleh diasumsikan sebagai persentase tanpa validasi penjual.
2. **Keterikatan Tarif Selepan (`grinding_fee`)**:
   * Disiapkan default `0.00` pada `recipe_configurations` dan `orders` sesuai dokumen.
   * *Status*: Jika tarif selepan seragam untuk seluruh racikan, nilainya dapat diatur sama pada setiap baris preferensi di `recipe_configurations`.
3. **Format Rincian Resep**:
   * Disiapkan menggunakan `JSON` pada `saved_recipes.recipe_details` sesuai dokumen rancangan.
